# Soccer public-display candidates (sanitized)

These copies are for a website or paper supplement. They do **not** replace the frozen scientific files.

- `soccer_full_demo_web.mp4` — re-encoded from the accepted MuJoCo Full preview (CRF 28, same 960×720, 24 fps, 144 frames). Robot and ball trajectories are unchanged; this file is a display encode only. SHA-256 `3d5fcef1a8500c2a591f6a5a51661f01a1b482bb9cc95b4e6e0f8482af6c7801`.
- `fig_robot_events.png` — six frozen-Full frames (no source video).
- `fig_interaction_timeline.png` — supplied event timeline.
- `fig_results_reuse.png` — reused metrics card.
- `summary.csv` — paper summary numbers.
- `event_metadata.json` — frame index and original-time mapping.

Not included: the human source video, source-to-robot frames, GVHMR weights, or G1 meshes.

The demo is kinematic reference motion with a prescribed ball path, not physical football dynamics. Event labels were supplied, not discovered by a coupled optimizer.

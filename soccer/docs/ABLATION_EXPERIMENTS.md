# Touch Ladder 足球消融实验

实验日期：2026-10-04  
实验对象：当前 203–209 s、144 帧 Touch Ladder 本地序列  
实验性质：单序列内部消融；不是总体 benchmark、动捕误差或动力学验证。

## 1. 研究目的

该实验回答四个问题：

1. 通用 IK 在不理解足球事件时能达到什么程度；
2. 支撑脚和脚底约束是否减少脚部滑移；
3. 区分接球脚、传球脚及事件帧后是否改善脚球关系；
4. 球事件修正和站位修正是否使足球穿过正确通道并接触正确脚。

四组实验使用相同的 SMPL-X 输入、G1 模型、144 帧时间轴、优化器和 340 次
迭代。前三组重新优化；Full 直接复制当前已验收版本，确保 Full 与项目最终视频
完全一致。

## 2. 实验组

### Basic IK

保留所有组共有的关键点、根部、朝向、关节平滑、骨盆起伏和上身目标。关闭：

- 支撑脚防滑和脚底约束；
- 发力脚事件加权和发力脚速度目标；
- 球—事件修正；
- 传球通道站位修正。

### + support

在 Basic IK 上加入不使用足球标签的通用支撑估计。支撑概率由源人体左右脚的高度
和水平速度计算，再启用支撑脚滑移与脚底高度损失。

### + event semantics

在 + support 上加入固定事件标注：

- 接球/传球参与者；
- 接球帧和传球帧；
- 接球脚和发力脚；
- 发力腿关键点加权；
- 发力脚速度匹配；
- 事件窗口内减少对发力腿的平滑抑制。

该组仍使用与前两组相同的源动作接触插值球轨迹，不执行球或站位修正。
论文定性图中将该列写为 `+ Support & Event Semantics`，因为它累积包含支撑约束，
避免将其误解为只增加事件语义。

### Full

在事件语义基础上使用当前验收版本的：

- 接球与传球分阶段球位置；
- 指定标志桶通道；
- 第一、第三脚的脚到脚直线传球；
- 其余传球的通道直线主体段；
- 接触站位和可见跳步窗口内的横向位置修正。

## 3. 评价指标

### 脚球关系

- 目标脚距离：固定接球/传球帧的球心—标注脚尖距离；
- 错误脚距离：同帧球心—另一只脚尖距离；
- 球面接触误差：`abs(球心—目标脚距离 - 0.11 m)`；
- 脚侧裕量：错误脚距离减目标脚距离，越大表示脚侧越明确。

第 0 帧的左脚只作为片段开头上下文，不计作接球样本；第 0 帧右脚传球仍计入。

### 机器人动作

- 支撑脚滑移：每个传球事件从 `kick-3` 到 `kick+1`，统计标注发力脚对侧脚尖的
  水平累计位移；
- 穿地代理：脚踝/脚尖关键点低于 0.012 m 阈值的深度；
- 骨盆垂直抖动代理：骨盆 Z 二阶差分乘以 `24²` 后的 RMS。

穿地指标基于关键点而不是网格碰撞，骨盆指标也不是 IMU 或动力学测量。

### 球轨迹和通道

- 曲率代理：标志桶中心 X 前后 0.55 m 范围内的路径长度/弦长超额；
- 方向变化：同一中央范围内累计航向变化；
- 标志桶表面净空：最小中心距离减去 0.11 m 球半径和 0.06 m 桶半径；
- 通道穿越误差：足球经过标志桶 X 时与目标通道 Y 的绝对差；
- 接触脚通道误差：传球脚/接球脚 Y 与该次目标通道 Y 的差。

## 4. 定量结果

- 目标脚距离均值：0.2087 m；
- 错误脚距离均值：0.4093 m；
- 球面接触误差：0.1024 m；

- 通道穿越误差：0.7038 m；
- 接触脚通道误差：0.6440 m。

### + support

- 目标脚距离均值：0.2092 m；
- 错误脚距离均值：0.4082 m；
- 球面接触误差：0.1026 m；
- 脚侧裕量：0.1990 m；
- 支撑脚滑移：0.1060 m/事件；
- 最大穿地代理：0.01310 m；
- 骨盆垂直加速度 RMS：6.491 m/s²；
- 最小标志桶表面净空：−0.1321 m；
- 通道穿越误差：0.7038 m；
- 接触脚通道误差：0.6441 m。

相对 Basic IK，通用支撑约束只把事件窗口滑移降低约 3.5%，对脚球关系和通道没有
实质影响。最大穿地代理没有改善，说明当前平均脚底损失不能保证最坏帧更优。

### + event semantics

- 目标脚距离均值：0.2009 m；
- 错误脚距离均值：0.4153 m；
- 球面接触误差：0.0941 m；
- 脚侧裕量：0.2144 m；
- 支撑脚滑移：0.0716 m/事件；
- 最大穿地代理：0.01565 m；
- 骨盆垂直加速度 RMS：7.043 m/s²；
- 最小标志桶表面净空：−0.1321 m；
- 通道穿越误差：0.7038 m；
- 接触脚通道误差：0.6475 m。

相对 Basic IK，事件语义使目标脚距离降低约 3.8%，球面误差降低约 8.2%，支撑脚
滑移降低约 34.8%。但是它没有改变球轨迹，所以足球仍穿过标志桶，通道误差也没有
改善；垂直加速度和最坏穿地代理反而升高。

### Full

- 目标脚距离均值：0.0898 m；
- 错误脚距离均值：0.4862 m；
- 球面接触误差：0.0220 m；
- 脚侧裕量：0.3964 m；
- 支撑脚滑移：0.0964 m/事件；
- 最大穿地代理：0.01355 m；
- 骨盆垂直加速度 RMS：7.213 m/s²；
- 最小标志桶表面净空：+0.0152 m；
- 通道穿越误差：0.01545 m；
- 接触脚通道误差：0.2244 m。

相对 Basic IK：

- 目标脚距离降低约 57.0%；
- 球面接触误差降低约 78.6%；
- 脚侧裕量提高约 97.7%；
- 支撑脚滑移降低约 12.3%；
- 通道穿越误差降低约 97.8%；
- 接触脚通道误差降低约 65.1%；
- 标志桶表面净空从 −0.1321 m（几何重叠）变为 +0.0152 m。

Full 的骨盆垂直加速度 RMS 比 Basic IK 高约 10.7%，支撑脚滑移也高于
`+ event semantics`。这说明当前站位/跳步修正换取了更正确的球脚和通道对齐，
但仍需要更平滑的全身轨迹或足步规划，不能声称所有运动质量指标都得到改善。

## 5. 曲率指标解释

四组在标志桶中央范围内的路径长度超额都接近 0，平均方向变化也接近 0°。原因是
无修正基线本身就是接触点之间的分段直线插值，而 Full 也显式保持通道中央段直线。
因此该指标验证了“中央段不是弧线”，但不能区分四组。

真正区分方法的是：

- 直线是否通过正确通道；
- 直线是否避开标志桶；
- 端点是否到达正确脚；
- 接球和传球是否使用正确脚侧。

## 6. 结论

本实验支持以下结论：

1. 单独增加通用支撑约束只能小幅减少支撑脚滑移；
2. 脚侧和事件语义能够改善发力/支撑角色，并显著减少事件窗口滑移；
3. 仅改机器人动作无法修复错误的足球通道；
4. 球事件修正与站位修正是改善脚球距离、脚侧裕量、通道误差和标志桶净空的主要
   因素；
5. 当前 Full 仍存在垂直抖动和最坏帧穿地代理未改善的问题，未来需要加入显式最大
   穿地惩罚、足步规划或轨迹后处理。

由于只有一个序列、每组一次确定性运行，本实验不提供方差、显著性检验或跨样本
泛化结论。

## 7. 站位修正隔离实验

补充 `Full - Position Correction`：沿用 `+ Support & Event Semantics` 的机器人
轨迹，并施加与 Full 相同的球脚吸附、直线通道和标志桶几何，但不执行机器人横向
站位修正。

相对该变体，Full 将通道穿越误差从 0.2010 m 降至 0.01545 m，将接触脚通道误差
从 0.6475 m 降至 0.2244 m，并将最小标志桶表面净空从 −0.1286 m 提升到
+0.0152 m。这说明站位修正对当前通道几何是必要的。

代价是 Full 的根部 jerk 从 395.38 增至 784.32 m/s³，关节 jerk 从
1086.83 增至 1241.59 rad/s³，最大脚网格穿地也从 0.02232 m 增至
0.02699 m。因此论文应表述为“站位修正显著改善几何一致性，但降低轨迹平滑性”，
而不是无条件改善。

结果位于：
`data/exports/touch_ladder_demo/paper_eval/position_ablation/`。

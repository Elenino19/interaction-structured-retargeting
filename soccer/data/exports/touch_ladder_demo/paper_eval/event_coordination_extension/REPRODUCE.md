# Reproduction

All commands run from the project root `$HOME/Projects/soccer_retarget`.
Python: `join/.venv/bin/python` (torch CPU, pytorch_kinematics, mujoco, matplotlib);
`MUJOCO_GL=egl` for headless rendering. `ffmpeg` is used for frame extraction.
Nothing below writes to `data/exports/touch_ladder_demo/g1/`, `ball_cones.npz`, `ball_cones.json` or the accepted
preview; those are read only. Re-running overwrites only files under
`data/exports/touch_ladder_demo/paper_eval/event_coordination_extension/`.

```bash
PY=join/.venv/bin/python
OUT=data/exports/touch_ladder_demo/paper_eval/event_coordination_extension

# Phase 3 — controlled fixed-ball comparison, shared frozen reference (primary). ~40 s total.
MUJOCO_GL=egl $PY scripts/run_fixed_ball_event_ablation.py --stationing frozen_reference
#   -> $OUT/fixed_ball_ablation/frozen_reference/{event_off,event_on,event_on_full_recipe}/
#      robot_a.npz robot_b.npz windows_{a,b}.npz scales.json ball_cones.npz (verbatim frozen copy)
#      soccer_scene.xml preview.mp4 experiment.json ; manifest.json

# Phase 3 (secondary) — same pair with current-code stationing + post-alignment, documents the dependency.
MUJOCO_GL=egl $PY scripts/run_fixed_ball_event_ablation.py --stationing current_code --variants event_off event_on

# Phase 2/4 — event-chain evaluator over all variants (existing ablations + fixed-ball runs).
MUJOCO_GL=egl $PY scripts/evaluate_event_chain.py
#   -> $OUT/event_metrics.csv transfer_chain_metrics.csv event_chain_summary.csv
#      fixed_ball_ablation.csv threshold_sensitivity.csv event_chain_metrics.json

# Phase 4 — figures.
$PY scripts/make_event_chain_figures.py
#   -> $OUT/interaction_timeline.{png,pdf} qualitative_comparison.{png,pdf} figure_metadata.json

# Integrity check of frozen inputs (expected hashes in manifest.json / pipeline_dependency_audit.md).
sha256sum data/exports/touch_ladder_demo/g1/robot_a.npz data/exports/touch_ladder_demo/g1/robot_b.npz \
          data/exports/touch_ladder_demo/ball_cones.npz data/exports/touch_ladder_demo/ball_cones.json \
          data/exports/touch_ladder_demo/comparison/current_hop_timed_lateral.mp4

# Unit tests (system python3 is enough).
python3 -m unittest discover -s tests -v
```

Options: `--iterations N` (default 340), `--force` to recompute an existing variant, `--skip-render` to skip MuJoCo
previews (the scene XML is still built so mesh metrics work), `--skip-mesh` on the evaluator to skip MuJoCo mesh
probes.

Determinism: the IK is float64 CPU Adam from a fixed initialisation; repeated runs on this machine reproduce the
variant NPZs. The accepted Full robots are **not** regenerated by these scripts (see
`pipeline_dependency_audit.md` §5).

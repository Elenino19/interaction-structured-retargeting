Interaction-Structured Motion Retargeting for Multi-Party Humanoid–Object Interactions

Buwen Zhang. Draft v6.2. This page is local and unpublished.

Two studies, one question: how an explicit interaction state becomes kinematic reference motion for a pair of Unitree G1 humanoids.

Overview Join Soccer Results Paper and code Citation

Abstract

Collaborative contact is not two independent poses standing near an object. On six CORE4D carry clips we retarget both people onto 29-DoF humanoids while the object pose stays an input. The final coupled method, EXT-JC, adds a joint-contact product to an object-aware objective and then repairs frames where clearance smoothing drives the hand into the object. Frozen v41 remains the visual baseline. It is not relabeled as EXT-JC.

A second study takes one 144-frame passing drill. Each humanoid is solved alone from a supplied actor, foot, and time annotation. The ball is written afterward. That case study specifies an interaction. It does not jointly optimize the two robots, and it does not discover the events.

All released motions are kinematic references. They are not dynamically stable controllers, motion-capture ground truth, or real-robot executions.

Method overview

Join · coupled

EXT-JC w10 + repair

Palmar anchors on the object, a per-robot geometry stack, then LJC = mean (1 − s1 s2) on source joint-carry frames, weight 10. A separable surrogate uses (s1 + s2) / 2 with the same repair. Cold-start J4 is an ablation, not the frozen v41 reference.

Soccer · sequential

Independent IK, then the ball

Two Adam solves that never read each other. Event windows set the active foot and a kick-velocity term. snap_ball_to_g1_feet places the ball on the annotation and rolls it through the cone lanes. Rerunning the current script does not reproduce the frozen joints.

Join

Six CORE4D-Real clips, action join, obstacle box, sequences 018, 019, 020, 108, 109, and 110. Train/dev 018/019/108, validation 020, test 109/110.

The comparison videos are not on this page. They contain the CORE4D box, and that geometry is not cleared for redistribution. The quantitative table is the bundled repair note, not a guessed manuscript figure.

Join demo media: withheld pending a license decision on CORE4D-derived renders. Code and numeric tables are in the repository under join/ and evaluation/join/.

Soccer

Frozen Full, 144 frames at 24 fps. Kinematic reference, prescribed ball, supplied labels. Not physical football dynamics.
